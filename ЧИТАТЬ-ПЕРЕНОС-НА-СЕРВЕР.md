# Перенос DWGToBundleTaskAddIn на сервер — пошагово

Пакет собран с машины-источника (13.10.2026). Ниже: что установить, что скопировать, где взять, порядок действий.

## 0. Что лежит в этом пакете
```
Перенос-на-сервер\
  runtime\
    DWGToBundleTaskAddIn.dll      <- сам аддин (v1.0.2.0, 100864 байт) — движок dwg2pdf встроен внутрь
    EPDM.Interop.epdm.dll         <- COM-взаимодействие PDM (рядом с DLL на время regasm)
  register\
    regasm-register.bat           <- регистрация через RegAsm (нужен .NET, даёт полное дерево COM) [РЕКОМЕНДУЮ]
    fix-register-hklm.bat         <- регистрация через reg.exe (если нет RegAsm), полное HKLM с version-subkey
    install-register-1.0.2.0.bat  <- копия DLL + регистрация HKLM (внимание: править путь SRC, см. п.3)
  docs\
    НАЧАТЬ ЗДЕСЬ.txt              <- краткая шпаргалка
    README.md                     <- полное описание задачи/настроек
    dwg2pdf.bat                   <- движок-референс (в DLL уже встроен; нужен только для override)
    reapp.bat                     <- чистка кэша плагинов PDM (если аддин не перезагружается)
  source\                          <- чистые исходники (для пересборки; без .git/obj/bin)
  SHA256SUMS.txt                   <- контрольные суммы (сверка целостности после копирования)
```

## 1. УСТАНОВИТЬ на сервере (этих файлов в пакете НЕТ — они только установлены, не лежат Installer'ами)
| Компонент | Зачем | Где взять | Версия на источнике |
|---|---|---|---|
| **.NET Framework 4.8 (x64)** | среда выполнения аддина | https://dotnet.microsoft.com/download/dotnet-framework/net48 (Offline Installer) | установлен (Release 533509) |
| **AutoCAD 2020** | нужен `accoreconsole.exe` — в нём крутится встроенный движок | ваш Autodesk-аккаунт / установочный носитель + лицензия | 2020, accoreconsole 23.1.47.0.0 |
| **Ghostscript** | перевод PDF в ч/б + проверка непустоты | https://ghostscript.com/releases/gsdnld.html (AGPL, 64-bit) | 9.52 (32-бит, от PDFCreator) |

Важно по путям (движок ищет по умолчанию):
- `accoreconsole.exe` — `C:\Program Files\AutoCAD\AutoCAD 2020\` (на источнике — `D:\Program Files\AutoCAD\AutoCAD 2020\`). Если на сервере иной путь — укажи полный путь в поле задачи «accoreconsole.exe».
- `gswin64c.exe`/`gswin32c.exe` — `C:\Program Files\PDFCreator\Ghostscript\bin\` или `C:\Program Files\gs\gs*\bin\`, либо в PATH. Если иной — путь в поле задачи «Ghostscript».

## 2. СКОПИРОВАТЬ на сервер
1. Создай папку `C:\PDM\DWGToBundleTaskAddIn` (если её нет).
2. Скопируй из `runtime\`:
   - `DWGToBundleTaskAddIn.dll` -> `C:\PDM\DWGToBundleTaskAddIn\DWGToBundleTaskAddIn.dll`
   - `EPDM.Interop.epdm.dll`    -> `C:\PDM\DWGToBundleTaskAddIn\EPDM.Interop.epdm.dll`
3. Скопируй папку `register\` куда удобно (например, в `C:\PDM\DWGToBundleTaskAddIn\`).
4. Сними блокировку, если аддин уже стоял: закрой окно задачи, при необходимости выполни `docs\reapp.bat` от администратора.

## 3. ЗАРЕГИСТРИРОВАТЬ (от «От имени администратора», на той машине, где работает PDM Agent/Card)
Вариант А (предпочтительно, есть .NET): `register\regasm-register.bat`
  - берёт DLL из `C:\PDM\DWGToBundleTaskAddIn\DWGToBundleTaskAddIn.dll`, снимает старый HKCU/HKLM, делает `RegAsm /codebase`, проверяет version-subkey.
Вариант Б (если RegAsm нет): `register\fix-register-hklm.bat`
  - пишет руками полное HKLM-дерево (аналог regasm /codebase). Тоже берёт DLL из `C:\PDM\DWGToBundleTaskAddIn`.
Вариант В: `install-register-1.0.2.0.bat` — ПЕРЕД запуском ПРАВОЙ КЛИК -> Изменить и поправь `set "SRC=..."` на путь к `runtime\DWGToBundleTaskAddIn.dll` (там захардкожен путь источника `D:\progs\...`). Иначе используй А/Б.

## 4. НАСТРОИТЬ в админке PDM (ConisioAdmin / Администрирование)
1. Vault -> Add-ins: удали старую запись `DWGToBundleTaskAddIn` (если есть) -> Add -> укажи `C:\PDM\DWGToBundleTaskAddIn\DWGToBundleTaskAddIn.dll`.
2. Команда = **Task Handler** (не Shell Command).
3. Если аккаунт службы PDM другой — дай ему **чтение** на папку `C:\PDM\DWGToBundleTaskAddIn`.
4. Создай/пересоздай задачу: тип «Обновить карточки…», настройка «DWG в ч/б PDF + карточка».
   - Переменные карточки: «Номер чертежа», «Наименование чертежа», `pdf` (целое). Обязательно: исходник проходит проверку -> `pdf=1`; не прошёл -> `pdf=0` и PDF НЕ грузится.
   - Режимы: «Пустые листы» (удалять/оставлять), «Схема» (в конце/только/выкл), «Масштаб из рамки» (выкл/по рамке/только), «Имя PDF» (по рамке/исходник).
   - Поля движка: `accoreconsole.exe` и `Ghostscript` — заполни, если пути на сервере отличаются от п.1. Таймаут 1–28 мин (по умолч. 5).
5. Перезапусти службу агента (или выполни задачу в своей интерактивной сессии, как на источнике).

## 5. ПРОВЕРИТЬ
1. Прогони тестовый DWG. Лог: `%APPDATA%\DWGToBundleTaskAddIn\DWGToBundleTaskAddIn.log`.
2. Ожидаемое в логе: строки `NETLOAD ... Loaded by application manager` (движок встроен — отдельного файла dwg2pdf.bat на сервере быть не должно) и `PDF проверен: ... непустых страниц: N`.
3. PDF в архиве должен быть ч/б; в карточке `pdf=1`. Для заведомо «пустого» DWG — `pdf=0` и PDF не загружается (тест запрета).
4. Движок сам распаковывает `SheetLayoutDistributor.dll` в `%APPDATA%\DWGToBundleTaskAddIn\engine\` — для аккаунта службы PDM должно быть право на запись в свой `%APPDATA%`.

## 6. Целостность (сверить после копирования на сервер)
```
certutil -hashfile C:\PDM\DWGToBundleTaskAddIn\DWGToBundleTaskAddIn.dll SHA256
```
Должно совпасть со значением в `SHA256SUMS.txt` (строка runtime\DWGToBundleTaskAddIn.dll).
