# DWGToBundleTaskAddIn

add-in SWE-PDM for DWG to PDF convertation all formats

## Версия 1.0.2.14

Исторический снимок PDM-аддина DWG/DXF → чёрно-белый PDF. Исходники и готовая DLL
восстановлены из резервной копии, сделанной до изменений 1.0.2.15.

- `runtime/DWGToBundleTaskAddIn.dll` — оригинальная DLL 1.0.2.14, 105472 байта.
- `runtime/EPDM.Interop.epdm.dll` — interop-библиотека из исходного проекта.
- `source/DWGToBundleTaskAddIn/Source` — исходники аддина и встроенные ресурсы движка.
- `source/SheetLayoutDistributorNW` — исходники AutoCAD-плагина этой версии.
- `register` и `docs` — сохранённые установочные скрипты и документация исходного проекта.
- `SHA256SUMS.txt` — контрольные суммы файлов текущего снимка.

Для работы нужны SOLIDWORKS PDM, .NET Framework 4.8, AutoCAD 2020 и Ghostscript.
AutoCAD-плагин и bat встроены в основную DLL. Публикация существующего PDF использует
разрегистрацию и регистрацию новой версии; после успеха аддин ставит `pdf=1`,
создаёт связь PDF → DWG и выполняет настроенный переход.

Сборка аддина на Windows: `source/DWGToBundleTaskAddIn/Source/build.cmd`.
Пути к установленным PDM/AutoCAD/Ghostscript нужно сверить с целевой машиной.
Документы и имена установочных скриптов сохранены из старого проекта и местами
содержат прежние номера версий; версия DLL определяется её FileVersion.

Это именно 1.0.2.14: новые изменения запуска задачи через ПКМ из 1.0.2.15 и защиты
экспорта/загрузки DWG из 1.0.2.16 в снимок не включены. Старый локальный запуск
конвертации из меню, существовавший в 1.0.2.14, сохранён.
Тестовый проект этой версии имеет ранее выявленные ошибки компиляции из-за
устаревших вызовов методов; исправления из новых версий сюда не переносились.
