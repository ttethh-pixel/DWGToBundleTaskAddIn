# Проверки

Нужны .NET SDK 8 и Ghostscript. Из корня проекта:

```
dotnet run --project Tests/Tests.csproj -- "C:\Program Files\gs\gs10.05.1\bin\gswin64c.exe" "C:\Temp\dwg-pdf-validation-tests"
```

Дополнительными аргументами можно передать реальные непустые PDF.
Тестовая программа создаёт PDF-фикстуры только в указанной папке результатов.
Тесты карточки используют подмены интерфейсов; они не подключаются к реальному хранилищу.

Для приёмки на Windows: запустить задачу на хорошем DWG, на DWG с белым PDF и на наборе
из обоих. Проверить: хороший PDF добавлен; пустой не добавлен; старый PDF не изменён;
`pdf=0` у отклонённого исходника во всех конфигурациях; при успехе значение не меняется.
Отдельно проверить отказ записи при отсутствии прав на переменную и повторный запуск
после сброса `pdf` потоком.

Версия 1.0.2.0: дополнительно проверены добавление нового PDF, новая версия существующего,
ошибка регистрации с отменой собственной разрегистрации, отказ по занятости и сверка архивных байтов.
Тесты публикации используют подмену хранилища; поведение конкретного PDM проверять на Windows.
